Ambiguity-Aware Multimodal Editing for Code-Based Visualization

Anonymous Authors

Natural-language follow-up questions require AI model calls, so this page presents only a selection of prepared direct manipulation and inline widget examples.

ACME follows our ambiguity-aware editing framework to interpret editing requests, identify unresolved aspects of the intended change, and select appropriate clarification interactions. The system instantiates and configures predefined inline widgets, or dynamically generates direct manipulation modules with visual guidance. During generation, it establishes mappings between interaction outputs and the corresponding chart configuration; when necessary, it modifies the rendering code to expose the required properties as configuration parameters.

The examples below let you try these prepared interactions directly. Your adjustments update the chart configuration and are reflected in the visualization. The original visualizations are sourced from the D3 Gallery and normalized using the process described in Section 5.1 of the paper.
